# プライバシーポリシー — リダイレクト返礼ピン (yt-redirect-pin)

最終更新: 2026-08-06

本拡張機能 (以下「本拡張」) の開発者は、利用者のデータの取り扱いについて以下のとおり定めます。

## 収集・送信するデータ

**本拡張は、いかなるデータも外部へ送信しません。**

- 本拡張はネットワーク通信を一切行いません (サーバへの送信、外部 API の呼び出し、
  解析・広告用の SDK の組み込みのいずれもありません)。
- 開発者が利用者のデータを閲覧・取得することはありません。

## ブラウザ内に保存するデータ

本拡張は、動作に必要な次のデータを **Chrome の拡張機能ストレージ (`chrome.storage.sync`)** に
保存します。保存先は利用者のブラウザおよび、利用者が Chrome の同期を有効にしている場合は
利用者自身の Google アカウントの同期領域です。

| 保存する内容 | 目的 |
|---|---|
| 動作設定 (有効/無効、投稿文テンプレート、固定モード、クールダウン秒数、診断ログの有無) | 拡張の挙動を利用者の指定どおりに保つため |
| 呼び名の辞書 (ライブリダイレクトの送信元チャンネルの URL・利用者が付けた呼び名・最後に受け取った時刻) | 投稿文に差し込む呼び名を決めるため |

これらは利用者のブラウザの中だけに存在します。拡張機能を削除すると、Chrome の拡張機能
ストレージから削除されます。

## 閲覧するページの内容

本拡張のコンテンツスクリプトは `https://studio.youtube.com/live_chat*` でのみ動作し、
そのページ上でライブリダイレクトの受信通知を探し、ライブチャットへの投稿と固定を行います。
読み取ったページの内容は、上記の目的のためにブラウザ内で処理するだけで、保存も送信もしません
(「診断ログ」を有効にした場合、検知の切り分けのためにブラウザの開発者コンソールへ出力しますが、
これも利用者の画面の中だけの話です)。

本拡張は `https://studio.youtube.com/*` 以外のページにはアクセスしません。

## 第三者への提供

ありません。送信していないため、提供する先もありません。

## 権限を求める理由

| 権限 | 理由 |
|---|---|
| `storage` | 上記の設定と呼び名の辞書を保存するため |
| `https://studio.youtube.com/*` (host permission) | ライブ配信の管理画面のライブチャットで、受信通知の検知・投稿・固定を行うため |
