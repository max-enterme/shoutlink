# プライバシーポリシー — 返礼リンク (shoutlink)

最終更新: 2026-09-10

本拡張機能 (以下「本拡張」) の開発者は、利用者のデータの取り扱いについて以下のとおり定めます。

## 収集・送信するデータ

**本拡張は、利用者のデータをどこへも送信しません。**

- 開発者のサーバはありません。解析・広告用の SDK も組み込んでいません。
- 開発者が利用者のデータを閲覧・取得することはありません。

### 次の通信を行います

以前の版は「ネットワーク通信を一切行いません」と記載していましたが、**コメント返しの機能
(下記) を追加したことにより、次の通信を行うようになりました。通信先は 2 か所です。**

| いつ | どこへ | 何のために | 何を送るか |
|---|---|---|---|
| 利用者が**設定ページ**で、辞書のある行の「コメントに反応する」を **ON にしたとき**、**「チャンネル ID を取得」を押したとき**、**「まとめて再試行」を押したとき**、または**「アイコンと表記名をまとめて取得」を押したとき** | **`https://www.youtube.com/` の、利用者が辞書に登録したチャンネルのページ** (登録されていない URL は取得しません)。**ON にしたとき・「チャンネル ID を取得」・「アイコンと表記名をまとめて取得」では、まだ控えていないアイコンの URL とチャンネルの表記名も同じ取得で読み取ります**(**チャンネルページの取得回数は増えません**。「まとめて再試行」はチャンネル ID だけを要求し、アイコンの URL・表記名は読み取りません) | そのチャンネルのページから**チャンネル ID (`UC…`) を読み取り、辞書に控える**ため(コメントの投稿者を照合するのに使います)。「アイコンと表記名をまとめて取得」では ID は要求せず、**アイコンの URL (`og:image`) と表記名 (`og:title`) を読み取るためだけ**にこのページを取得します | **利用者のデータは何も送りません。**ページを取得する通常の GET 要求だけです。**ログイン状態も送りません** (`credentials: 'omit'` — Cookie を付けないので、YouTube 側でアカウントに結び付きません。ただし**通常の Web アクセスと同じく、接続元の IP アドレスと、どのチャンネルのページを取得したかは YouTube 側に残ります**) |
| 上の行でチャンネルページからアイコンの URL を読み取れたとき(「コメントに反応する」を ON にしたとき・「チャンネル ID を取得」を押したとき・「アイコンと表記名をまとめて取得」を押したとき。**「まとめて再試行」ではアイコンを要求しません**)。いずれも**まだアイコンを控えていない行だけ**が対象です | **`https://yt3.googleusercontent.com/` の、直前に取得したチャンネルページの `og:image` が指すアイコン画像**。`/channel/UC…` 形で登録されていてチャンネル ID を通信せずに読み取れる行でも、**アイコンが未取得ならこの通信のために上の行のチャンネルページ取得が発生します** | **チャンネルのアイコンを取得し、辞書の一覧に丸いアイコンとして表示する**ため。**表示専用**で、照合や投稿文には使いません | 通常の GET 要求のみ。Cookie は付けません。控えたアイコンは `chrome.storage.local` に data URL として保存され、**次からは取りに行きません** |

- **ライブチャットの画面 (`studio.youtube.com`) から本拡張が通信することはありません。**投稿と固定は、YouTube のページの入力欄とメニューを操作して行っています (通信するのは YouTube のページ自身です)。
- **設定画面の辞書タブを開いただけでは、何も取りに行きません。**上の表の引き金を押したときだけ通信します。
- 取得したページの内容は**チャンネル ID とアイコンの URL を取り出すためだけ**に使い、ページそのものは保存しません。
- **取得するのは、まだチャンネル ID (またはアイコン) を控えていない行だけ**です。控え終わった行は取りに行きません。`https://www.youtube.com/channel/UC…` の形で登録されている行は、**チャンネル ID については通信せずに** URL から読み取ります (アイコンは URL からは分からないため、チャンネルページの取得が必要です)。<br>取得に失敗した行は、利用者が**再試行を押したとき**と、**「コメントに反応する」を ON にし直したとき**にもう一度試します。
- 取得に失敗しても本拡張は壊れません。チャンネル ID の取得に失敗した行は**コメント返しの対象外になる**だけで、アイコンの取得に失敗した行は**一覧に頭文字の丸が出る**だけです。

## ブラウザ内に保存するデータ

本拡張は、動作に必要な次のデータを **Chrome の拡張機能ストレージ**に保存します。

| 保存する内容 | 保存先 | 目的 |
|---|---|---|
| 動作設定 (自動検知の有無、投稿文テンプレート、**コメント返しの有無**、**コメント返しの文面**、固定モード、手動トリガーの表示、診断ログの有無) | `chrome.storage.sync` (使えない環境では `local`) | 拡張の挙動を利用者の指定どおりに保つため |
| 呼び名の辞書 (ライブリダイレクトの送信元チャンネルの URL・利用者が付けた呼び名・**利用者が入力した自由文 2 種**・最後に受け取った時刻・**「コメントに反応する」のフラグ**・**照合用のチャンネル ID (`UC…`)**・**チャンネルアイコンの画像 (data URL)**・**チャンネルの表示名**) | **`chrome.storage.local`** (端末内のみ・同期しません) | 投稿文に差し込む呼び名と自由文を決めるため。**フラグとチャンネル ID は、誰のコメントに反応するかを決めるため。アイコンと表示名は一覧に表示するためだけ**で、照合や投稿文には使いません(**表示名は、呼び名を付けていない行にグレーで代わりに出します**) |
| 投稿履歴 (投稿できた相手のチャンネル URL・投稿した文面・時刻・配信の識別子・**投稿の種別**) | **`chrome.storage.local`** (端末内のみ・同期しません) | チャットを開き直したときの再投稿を防ぐため。**7 日を過ぎたもの・種別ごとに 200 件を超えた古いものは捨てます** (捨てるのは**次に投稿を記録するとき**なので、投稿が止まっている間は残ります) |

`sync` に置いたものは、利用者が Chrome の同期を有効にしている場合、
利用者自身の Google アカウントの同期領域を通じて他の端末にも複製されます。
**呼び名の辞書と投稿履歴は同期しません** (この端末の中だけに残ります)。設定ページからいつでも消せます。

> **呼び名の辞書の保存先は `chrome.storage.sync` から `chrome.storage.local` に変わりました。**
> `sync` には 1 項目あたりの容量上限があり、自由文を保存できるようにしたことで上限に近づくためです。
> 以前のバージョンで `sync` に保存されていた辞書は、**利用者の端末の中で 1 度だけ** `local` へ
> 複製されます (外部への送信は伴いません)。`sync` 側のデータは、他の端末で使えなくなるのを避けるため
> 削除していません。

自由文は利用者自身が入力するものです。**本拡張は内容を検査しません。**
入力した自由文は、テンプレートに `{msg}` が含まれている場合、
その送信元と判定された相手への投稿文に差し込まれてライブチャットに公開されます。
**自由文は 2 種類あり (リダイレクト返礼用とコメント返し用)、それぞれ別のテンプレートの
`{msg}` に差し込まれます。**一方が他方の投稿文に出ることはありません。

**照合用のチャンネル ID (`UC…`) は、利用者が辞書に登録したチャンネルの公開ページから
読み取った値**で、その相手のコメントを見分けるためだけに使います。投稿文には入りません
(投稿するのは辞書に登録されている URL のほうです)。

これらは利用者のブラウザの中だけに存在します。拡張機能を削除すると、Chrome の拡張機能
ストレージから削除されます。

## 閲覧するページの内容

本拡張のコンテンツスクリプトは `https://studio.youtube.com/live_chat*` でのみ動作し、
そのページ上でライブリダイレクトの受信通知**とライブチャットのコメント**を探し、
ライブチャットへの投稿と固定を行います。
読み取ったページの内容は、上記の目的のためにブラウザ内で処理するだけで、保存も送信もしません
(「診断ログ」を有効にした場合、検知の切り分けのためにブラウザの開発者コンソールへ出力しますが、
これも利用者の画面の中だけの話です)。

コメントについて読み取るのは、**投稿者のチャンネル ID・配信者自身の投稿かどうかの区別・
表示時刻**と、**本文**です (本文は、**自分が直前に投稿した文面と一致するコメントを弾く**ためだけに
使います。保存も送信もしません)。**投稿者の表示名は投稿文にも照合にも使いません** (第三者が自由に決められる
文字列であるため)。**辞書に登録されていない人のコメントは、照合が外れた時点で捨てます。**

**本拡張がページに読み込まれるのは `https://studio.youtube.com/live_chat*` だけです。**
`https://www.youtube.com/*` に対しては、上記「次の通信を行います」の取得を行うだけで、
**そのページに本拡張が読み込まれることはありません。**

## 第三者への提供

ありません。送信していないため、提供する先もありません。

## 権限を求める理由

| 権限 | 理由 |
|---|---|
| `storage` | 上記の設定と呼び名の辞書、投稿履歴を保存するため |
| `https://studio.youtube.com/*` (host permission) | ライブ配信の管理画面のライブチャットで、受信通知とコメントの検知・投稿・固定を行うため |
| `https://www.youtube.com/*` (host permission) | **設定ページから、利用者が辞書に登録したチャンネルのページを取得して照合用のチャンネル ID を読み取るため**、および**チャンネルのアイコンの URL (`og:image`) を読み取るため** (上記の表)。**このページにコンテンツスクリプトは注入しません** |

> **`www.youtube.com` の権限が増えたことについて。**
> インストール時の許可表示にこのホストが加わりますが、**本拡張がそこで動くようになったという
> 意味ではありません。**本拡張は過去に、`www.youtube.com` のライブチャットでもコンテンツスクリプトが
> 動いてしまい、他人の配信のチャットへ投稿するという不具合を起こしています (2026-08-06)。
> **今回増えたのはページを取得するための許可だけで、コンテンツスクリプトが動く範囲は
> `https://studio.youtube.com/live_chat*` のまま変わっていません**
> (この点は自動テストでも固定しています / [security-review.md](security-review.md) S10)。
