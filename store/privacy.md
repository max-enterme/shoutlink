# プライバシー タブの回答 (そのまま貼れる文面)

Chrome ウェブストア デベロッパーダッシュボードの「プライバシー」タブ。
**ここの記述と実装が食い違うと審査で落ちる。**実装を変えたらここも直すこと。

---

## 単一用途の説明 (Single purpose)

```
YouTube Studio のライブチャット画面で、他チャンネルから受け取ったライブリダイレクトを検知し、
送信元チャンネルの URL を含む返礼メッセージをライブチャットへ投稿して固定する。これ以外の機能は持たない。
```

## 権限の正当性 (Permission justification)

### `storage`

```
利用者が設定した投稿文テンプレート・固定モード・クールダウン秒数・機能の ON/OFF と、
送信元チャンネルごとの「呼び名」の対応表を保存するために使う。
保存先はブラウザの拡張機能ストレージのみで、外部への送信は行わない。
```

### ホスト権限 `https://studio.youtube.com/*`

```
本拡張の機能はすべて YouTube Studio のライブチャット画面 (studio.youtube.com/live_chat) の
DOM 上で完結する。リダイレクト受信の通知はこの画面にしか現れず、チャットへの投稿と
メッセージの固定を行う API も存在しないため、当該画面のコンテンツスクリプトとして
実行する以外に実現手段がない。他のホストへはアクセスしない。
```

> www.youtube.com を対象から**意図的に外している**ことは、権限を絞っている根拠として
> 説明に使える (他人の配信のチャットも開けてしまい、誤爆するため除外した)。

## リモートコード (Remote code)

```
いいえ。リモートでホストされたコードは使用しない。
拡張に同梱した JavaScript のみを実行し、eval / new Function / 外部スクリプトの読み込みは行わない。
```

## データ利用の申告 (Data usage)

収集するデータの種類 — **すべてチェックしない**。

| カテゴリ | 該当 | 備考 |
|---|---|---|
| 個人を特定できる情報 | なし | |
| 健康情報 | なし | |
| 財務・支払い情報 | なし | |
| 認証情報 | なし | |
| 個人的な連絡先 | なし | |
| 位置情報 | なし | |
| ウェブ履歴 | なし | |
| ユーザーの操作 | なし | |
| ウェブサイトのコンテンツ | なし | チャット画面の DOM を読むが、保存も送信もしない |

> 「収集 (collect)」はストアの定義では **拡張の外へ持ち出すこと**を指す。
> 本拡張は `chrome.storage` にローカル保存するだけで、どこへも送らないため該当なし。

### 認証する 3 項目 (すべて「はい」にできる)

- 承認された用途以外でデータを販売・譲渡しない → **該当なし (そもそも扱っていない)**
- 単一用途と無関係な目的にデータを使用しない → **はい**
- 信用力の判断や与信目的でデータを使用しない → **はい**

## プライバシーポリシー URL

本文は [docs/privacy-policy.md](../docs/privacy-policy.md)。
**公開 URL を用意して、そのアドレスをここに入れる。**候補:

1. `max-website` (公開サイト) の 1 ページとして置く ← 最も素直
2. GitHub リポジトリを作って GitHub Pages で出す
3. 公開 Gist

> どれも「誰でもログイン無しで見られる」ことが条件。
> ストア側は URL の到達性を見るので、private リポジトリの blob URL は不可。

## 審査で説明を求められたときの補足文

レビュアーは実際に動かせない (YouTube のライブ配信中で、かつ他チャンネルから
ライブリダイレクトを受け取った瞬間にしか発火しないため)。聞かれたらこれを返す。

```
本拡張の主機能は、YouTube Studio のライブチャット画面 (studio.youtube.com/live_chat) で
「@<チャンネル名> とその視聴者が参加しました。」という通知が現れたことを契機に発火します。
この通知は、実際にライブ配信中で、かつ他チャンネルからライブリダイレクトを受け取ったときにのみ現れるため、
再現には配信環境が必要です。

配信環境を用意せずに確認できる範囲としては、次の 2 つがあります。

1. オプションページ (chrome://extensions から開けます) — 設定項目と、投稿文のプレビューを確認できます。
2. ライブチャット画面の右下に常設される手動トリガー「↩ 返礼」パネル —
   自動検知と同じ処理を、チャンネルを手で指定して実行できます。

外部への通信は一切行っていません。ソースは難読化しておらず、同梱の content.js は
esbuild でバンドルしただけのものです。
```
