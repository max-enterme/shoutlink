# ストア掲載情報 (そのまま貼れる文面)

Chrome ウェブストア デベロッパーダッシュボードの「ストアの掲載情報」タブに入れる内容。
文字数上限は Google 側の仕様。変えたら上限を確認すること。

---

## 名前 (上限 75 文字)

```
リダイレクト返礼ピン (yt-redirect-pin)
```

> `public/manifest.json` の `name` と一致させる。ストアはこちらを正とするが、
> インストール後の表示は manifest 側なので、食い違うと混乱する。

## 概要 / short description (上限 132 文字)

manifest の `description` がそのまま使われる。

```
配信中に受け取ったライブリダイレクトを検知し、送信元チャンネルの URL をライブチャットへ投稿して固定します。
```

## 詳細な説明 (上限 16,000 文字)

```
YouTube の配信で他チャンネルからライブリダイレクトを受け取ったとき、
送信元チャンネルへの導線をライブチャットに残すための拡張機能です。

配信中に「誰から来たのか」を確認して、チャンネル URL をコピーして、投稿して、固定する ——
この一連の操作を、リダイレクトを受け取った時点で自動で行います。

■ できること

・ライブリダイレクトの受信を検知する
・送信元チャンネルの表示名と URL を含むメッセージを、あなたのアカウントでライブチャットへ投稿する
・投稿したメッセージを固定する (固定するかどうかは設定で選べます)
・送信元ごとに「呼び名」を登録して、投稿文の宛名に使う
・自動検知が働かなかったときのために、チャット画面から手動で実行できるボタンを常設

■ 設定できること

・投稿文のテンプレート ({name} に表示名、{url} にチャンネル URL が入ります)
・固定モード
  - off … 投稿するだけで固定しない
  - ifEmpty … 既に固定されているメッセージが無いときだけ固定する (既定)
  - always … 既存の固定を上書きして固定する
・同一の送信元からの再投稿を抑える待ち時間 (既定 10 分)
・機能全体の ON / OFF

YouTube のチャット固定は 1 件しか置けないため、告知などを固定している配信者向けに
既定を ifEmpty にしてあります。

■ 動作する場所

YouTube Studio のライブ管理画面のライブチャット (studio.youtube.com) でのみ動作します。
www.youtube.com のライブチャットでは動作しません。他人の配信でも開けてしまい、
自分の配信かどうかを判別できないためです。ポップアウトも Studio 側のものを使ってください。

■ データの取り扱い

・外部への通信は一切行いません
・設定と呼び名の辞書は Chrome の拡張機能ストレージにのみ保存されます
・開発者があなたのデータを見ることはありません

詳しくはプライバシーポリシーをご覧ください。

■ ご注意

・投稿はあなた自身の YouTube アカウントで行われます。自動投稿を望まない場合は
  設定でオフにするか、手動ボタンからの実行だけを使ってください。
・YouTube の画面構造の変更によって動作しなくなることがあります。
・本拡張は YouTube および Google の公式製品ではなく、これらから承認・提携を受けたものでもありません。
  YouTube は Google LLC の商標です。
```

## 公開範囲

| 選択肢 | 向き |
|---|---|
| 一般公開 | 誰でも検索・インストールできる |
| **限定公開 (リンクを知っている人)** | URL を渡した人だけ。**まずはこれを推す** |
| 非公開 (テスター) | 指定した Google アカウントのみ |

> 審査は**どの公開範囲でも同じように通す必要がある**(掲載画像もプライバシー申告も必須)。
> 限定公開は「不特定多数のサポート要求を抱えない」ためのもの。

## 掲載画像

`store/assets/` に用意済み。すべて `npm run build && node scripts/make-store-assets.mjs` で
作った版下をブラウザで撮ったもの。

| ファイル | 用途 | 必須 |
|---|---|---|
| `promo-440x280.png` | 小プロモタイル | 必須 |
| `screenshot-1-options.png` | スクリーンショット (設定画面 上部) | 1 枚以上必須 |
| `screenshot-2-pin-mode.png` | スクリーンショット (固定モード / クールダウン) | |
| `screenshot-3-directory.png` | スクリーンショット (呼び名の辞書) | |

拡張のアイコン (128x128) は ZIP 内の `icons/icon128.png` が使われる。別途アップロードは不要。

### まだ足りない画像 (実配信でしか撮れない)

用意した 3 枚はすべて設定画面で、**機能そのものが動いている絵が無い**。
次の 2 枚を実配信で撮って差し替えると、審査でも掲載でも通りが良くなる:

1. ライブチャットに返礼メッセージが投稿され、**固定されている**ところ
2. チャット右下の手動トリガー「↩ 返礼」パネル

撮影後は 1280x800 か 640x400 にトリミングすること。**他人のチャンネル名・視聴者のコメント・
配信者本人の個人情報が写り込んでいないか**を必ず確認する。
